# UI/UX Specification — Incident Grouping & Bulk Action

> **สถานะ: PLANNING ONLY — ยังไม่มีการแก้ไข UI Components หรือ Pages ในระบบ**

---

## 1. Design System & Foundation

- **Framework:** Next.js 15 App Router + React 19
- **Styling:** Tailwind CSS + Radix UI / shadcn-compatible primitives + Lucide React Icons
- **Theme:** รองรับทั้ง Light & Dark Mode ตามธีมปัจจุบันของ Backoffice
- **Typography:** Prompt / Inter (ฟอนต์ภาษาไทยอ่านง่าย ชัดเจน)
- **Design Principles:**
  1. **Clarity First:** แยกชัดเจนระหว่าง "Incident แม่" (สรุปรวมภาพใหญ่) กับ "Reports ย่อย" (คำร้องจากประชาชน/นักศึกษา)
  2. **Zero Confusion Status:** สี Badge และสถานะของ Incident สื่อความหมายตรงตัว
  3. **Safety Guards:** มี Confirmation Modal เสมอเมื่อทำ Bulk Action หรือปลดคำร้อง (Unlink)
  4. **Smooth Workflows:** Multi-select ไม่ทำให้หน้ากระตุก แสดง Floating Action Bar ทันทีที่มีการเลือกรายการ

## 2. หน้าจอที่ 1: รายการ Incident (`/backoffice/incidents`)

### 2.1 Wireframe Layout

```
+---------------------------------------------------------------------------------------+
|  [Sidebar]  |  Incidents Management (การจัดการเหตุการณ์รวม)          [+ สร้าง Incident] |
|             |-------------------------------------------------------------------------|
|             |  [ ค้นหาตามรหัส/ชื่อ/สถานที่... ] [ ทุกสถานะ v ] [ ความสำคัญ v ] [ หมวดหมู่ v ] |
|             |-------------------------------------------------------------------------|
|             |  [ ] รหัส Incident     ชื่อเหตุการณ์        คำร้อง  ความสำคัญ  สถานะ   ผู้รับผิดชอบ  |
|             |-------------------------------------------------------------------------|
|             |  [ ] INC-20260925-001  ท่อประปาแตกหน้าตึก 1   (8)   [HIGH]    [กำลังทำ] สมชาย ช่างซ่อม|
|             |  [ ] INC-20260925-002  ไฟดับอาคารวิศวะ 3     (2)   [CRITICAL] [เปิด]   -ยังไม่มอบหมาย- |
|             |  [ ] INC-20260924-005  แอร์ไม่เย็นห้อง 402   (3)   [NORMAL]   [เสร็จ]  วิชัย ช่างไฟ   |
|             |-------------------------------------------------------------------------|
|             |  แสดง 1-10 จากทั้งหมด 45 รายการ                        [< หน้าก่อน] [1] [2] [ถัดไป >]|
+---------------------------------------------------------------------------------------+
```

### 2.2 Functional Elements & Interactions
- **Status Badges:**
  - `open`: สีฟ้า/น้ำเงิน (`bg-blue-50 text-blue-700 border-blue-200`)
  - `in_progress`: สีส้ม/อำพัน (`bg-amber-50 text-amber-700 border-amber-200`)
  - `resolved`: สีเขียว (`bg-emerald-50 text-emerald-700 border-emerald-200`)
  - `closed`: สีเทา (`bg-slate-100 text-slate-600 border-slate-200`)
- **Priority Badges:**
  - `critical`: สีแดงมีไอคอน Pulse Alert
  - `high`: สีส้ม
  - `normal`: สีฟ้า/เทา
  - `low`: สีเทาอ่อน
- **Report Count Pill:** แสดงจำนวนเคสย่อย เช่น `(8)` เมื่อ Hover จะขึ้น Tooltip แสดงรายชื่อ 3 เคสแรก
- **Quick Search & Filter:** Filter อัตโนมัติ (Debounce 300ms) ไม่ต้องกดปุ่มค้นหา

## 3. หน้าจอที่ 2: รายละเอียด Incident (`/backoffice/incidents/[publicId]`)

### 3.1 Wireframe Layout

```
+---------------------------------------------------------------------------------------+
|  <- กลับหน้ารวม Incidents                                                              |
|---------------------------------------------------------------------------------------|
|  INC-20260925-001 : ท่อประปาแตกหน้าอาคารเรียนรวม 1                                     |
|  [ความสำคัญ: สูง] [สถานะ: กำลังดำเนินการ v] [ผู้รับผิดชอบ: สมชาย ช่างซ่อม v]              |
|  สถานที่: หน้าอาคารเรียนรวม 1 ชั้น 1 | สร้างเมื่อ: 25 ก.ย. 2026 08:30 (โดย: จนท. รุ่งทิพย์)   |
|---------------------------------------------------------------------------------------|
|  [ แท็บ 1: คำร้องในกลุ่ม (8) ]  [ แท็บ 2: คำแนะนำเข้ากลุ่ม (3) ]  [ แท็บ 3: ประวัติ (5) ] |
|---------------------------------------------------------------------------------------|
|  [เลือกทั้งหมด] [ตอบกลับพร้อมกัน] [เปลี่ยนสถานะพร้อมกัน] [ปลดออกจากกลุ่ม]               |
|                                                                                       |
|  [v] R20260925-0012  น้ำท่วมลานจอดรถตึก 1    (สมหญิง)    [กำลังทำ]  25/09 08:15 [ปลดออก]|
|  [v] R20260925-0015  ท่อส่งน้ำหลักแตกชั้น 1   (ประเสริฐ)  [กำลังทำ]  25/09 08:22 [ปลดออก]|
|  [ ] R20260925-0021  น้ำไหลแรงดันตกทั้งตึก    (อาจารย์ ก) [รับเรื่อง] 25/09 08:40 [ปลดออก]|
+---------------------------------------------------------------------------------------+
```

### 3.2 รายละเอียดแต่ละแท็บ

#### แท็บ 1: คำร้องในกลุ่ม (Active Reports)
- แสดงตารางรายงานที่ผูกไว้กับ Incident
- Checkbox สำหรับเลือกหลายรายการเพื่อทำ **Bulk Action**
- ปุ่ม `[ปลดออก]` แต่ละแถว: เปิด Modal ให้กรอก "เหตุผลที่ปลดคำร้องออก" เพื่อเก็บ Audit Trail

#### แท็บ 2: คำแนะนำเข้ากลุ่ม (Suggestions & Recommendations)
- แสดงการ์ดรายการคำร้องที่ระบบ/AI วิเคราะห์ว่าน่าจะเป็นเรื่องเดียวกัน
- มีแถบ **Match Score** (เช่น 92% ความมั่นใจสูง)
- แสดง Chips ปัจจัยที่ตรงกัน: `[สถานที่ตรงกัน 90%]` `[หมวดหมู่เดียวกัน]` `[เวลาห่าง 15 นาที]`
- ปุ่ม `[ยอมรับ / รวมเข้า Incident]` และ `[ปฏิเสธ / ไม่ใช่เรื่องนี้]`

#### แท็บ 3: ประวัติการดำเนินการรวม (Bulk History & Audit Trail)
- แสดง Timeline บันทึกการทำ Bulk Update เช่น:
  - *"สมชาย ช่างซ่อม เปลี่ยนสถานะ 8 คำร้องเป็น 'แก้ไขแล้ว' เมื่อ 25/09 10:30"*
  - *"ส่งข้อความแจ้งเตือนทาง LINE ไปยังผู้แจ้ง 8 ราย สำเร็จ 8/8 ราย"*

## 4. ส่วนเสริมในหน้ารายการคำร้องเดิม (`/backoffice/reports`)

### 4.1 Bulk Floating Bar
เมื่อ Staff ติ๊กเลือก Checkbox ในตารางคำร้องมากกว่า 0 รายการ ให้แสดง Floating Bar ด้านล่างหน้าจอ:

```
+-------------------------------------------------------------------------------+
|  เลือกแล้ว 4 รายการ  |  [+ รวมเป็น Incident]  [เปลี่ยนสถานะ]  [ตอบกลับ]  [x ยกเลิก] |
+-------------------------------------------------------------------------------+
```

- ปุ่ม `[+ รวมเป็น Incident]`: เปิด Modal ถามชื่อ Incident, หมวดหมู่, ผู้รับผิดชอบ แล้วสร้าง Incident ทันที พร้อมย้ายทั้ง 4 เคสเข้าสังกัด
- ปุ่ม `[เปลี่ยนสถานะ]`: เปิด Modal ให้เลือกสถานะใหม่ + กรอกบันทึกการดำเนินการ
- ปุ่ม `[ตอบกลับ]`: เปิดหน้าต่างพิมพ์ข้อความสื่อสารถึงผู้แจ้งทั้ง 4 รายพร้อมกัน

### 4.2 Incident Link Badge
ในแถวตารางของ Report หากคำร้องใดผูกอยู่กับ Incident ให้แสดง Badge ลิงก์:
- ตัวอย่าง: `[🔗 INC-20260925-001]`
- เมื่อคลิกจะเปิดหน้ารายละเอียด Incident ทันที

## 5. ส่วนเสริมในหน้ารายละเอียดคำร้องเดิม (`/backoffice/reports/[publicId]`)

ในแถบด้านขวา (Sidebar Info) ของหน้ารายละเอียดคำร้อง:
- **กรณีที่ยังไม่ได้ผูกกับ Incident:**
  - แสดงกล่องการ์ด *"คำแนะนำ: อาจเกี่ยวข้องกับ Incident ที่กำลังเปิดอยู่"*
  - แสดงรายชื่อ 1-2 Incident ที่สถานที่หรือหมวดหมู่ตรงกัน พร้อมปุ่ม `[ผูกเข้ากับ Incident นี้]`
- **กรณีที่ผูกกับ Incident แล้ว:**
  - แสดงการ์ด *"คำร้องนี้อยู่ใน Incident: INC-20260925-001 (ท่อประปาแตกหน้าตึก 1)"*
  - แสดงสถานะของ Incident แม่
  - ปุ่ม `[ดูเหตุการณ์หลัก]` และปุ่ม `[ปลดออกจากเหตุการณ์]`

## 6. Modal Specifications

### 6.1 Create Incident Modal
- **Fields:**
  - หัวข้อ Incident (Text Input, Required)
  - รายละเอียดสรุป (Textarea, Optional)
  - หมวดหมู่หลัก & หมวดหมู่ย่อย (Select Cascading, Required)
  - สถานที่ / จุดเกิดเหตุ (Text Input, Auto-suggest)
  - ระดับความสำคัญ (Radio Group: ต่ำ / ปกติ / สูง / วิกฤต)
  - ผู้รับผิดชอบงาน (Select Staff, Optional)
  - รายการคำร้องเริ่มต้น (แสดง Pills ของ Report IDs ที่เลือกมา)

### 6.2 Bulk Status Change Modal
- **Fields:**
  - สถานะใหม่ (Select: รับเรื่องแล้ว / กำลังดำเนินการ / แก้ไขเสร็จสิ้น / ปิดเรื่อง)
  - หมายเหตุการเปลี่ยนสถานะ (Textarea, Required สำหรับบันทึกใน Timeline)
  - Checkbox: `[v] ส่งแจ้งเตือนผ่าน LINE ไปยังผู้แจ้งทุกคน (รวม 5 ราย)`
  - Warning Alert: *"การเปลี่ยนสถานะนี้จะมีผลกับคำร้องทั้ง 5 รายการทันที และสร้างบันทึกประวัติการทำงานในแต่ละรายการ"*

### 6.3 Bulk Reply Modal
- **Fields:**
  - ข้อความตอบกลับ (Textarea, มี Template ให้เลือก เช่น "ทีมช่างเข้าพื้นที่แล้ว", "กำลังรออะไหล่")
  - ตัวอย่างข้อความที่จะปรากฏใน LINE Flex Message (Live Preview Card)
  - Checkbox: `[v] บันทึกข้อความนี้ลงในรายงานย่อยทุกรายการ`
